# Agent Remote v1.0.1 — native CLI history in the phone app

Previous builds only showed sessions that Agent Remote itself had created, so chats that
were already in Codex/Claude/DSH on the PC were invisible. This release imports them.

## What changed

- On startup, agentd imports:
  - **Codex** threads (including paginated/older rollouts where readable),
  - **Claude Code** project transcripts,
  - **DeepSeek Harness** turn outlines and titles.
- Imported sessions appear in the existing iOS/Android project list with transcripts and
  **再開**.
- **Local import is automatic.** Cross-host sync is still opt-in: configure the encrypted
  relay (`AGENT_REMOTE_SYNC_*`) or a shared archive folder. There is no default cloud room,
  because that would expose one user's history to everyone.
- `AGENT_REMOTE_IMPORT_HISTORY=0` disables the startup scan.
- **Desktop 1.0.1** shares `~/.agent-remote/sessions`, imports the same history, and has a
  Sessions tab with project list, chat, approvals, models and resume.
- Phone apps are unchanged and compatible (iOS 0.4.0 / Android 0.5.0).
- agentd **0.6.1**.

## 日本語

これまでのビルドはAgent Remote経由で作ったセッションしか表示しておらず、PC側の
Codex/Claude/DSHに既にある会話が見えていませんでした。今回それを取り込みます。

- agentd起動時に **Codexスレッド / Claude Codeトランスクリプト / DSHターン概要** を
  自動インポート
- スマホアプリの既存プロジェクト一覧に履歴と **再開** が表示される
- **ローカル取り込みは自動**。ホスト間同期は従来どおりオプトインで、暗号化リレー
  （`AGENT_REMOTE_SYNC_*`）または共有フォルダを設定した場合のみ
- `AGENT_REMOTE_IMPORT_HISTORY=0` で取り込みを無効化
- **Desktop 1.0.1** は同じ `~/.agent-remote/sessions` を共有し、セッションタブで
  プロジェクト一覧・会話・承認・モデル・再開を操作可能
- スマホアプリは変更なし（iOS 0.4.0 / Android 0.5.0）、agentd **0.6.1**
