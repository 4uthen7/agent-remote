# Agent Remote v1.0.2 — reconnect without losing the chat

## Why it returned to the top screen

The phone app used to treat every WebSocket close as a hard disconnect and navigate back
to the connect screen. A short Tailscale/LAN interruption therefore looked like a failed
connection even though the session was still alive on the PC.

## What changed

- iOS/Android keep the current project, session and timeline when the socket drops.
- They reconnect with backoff (2–15 s) and re-subscribe to the same session, restoring
  the last snapshot.
- The composer is disabled only while disconnected; history stays readable.
- Native Codex/Claude/DSH history import from v1.0.1 remains in the host update.
- **Off-LAN requires a reachable endpoint** (Tailscale, VPN, or a TLS proxy). A
  `192.168.x.x` LAN URL cannot work over cellular; that is a network limitation, not the
  app switching screens.

Versions: iOS **0.4.1** / Android **0.5.1** / agentd **0.6.1** / Desktop **1.0.1**.

## 日本語

これまでWebSocketが切れるたびに接続画面へ戻していたため、TailscaleやWi-Fiの一瞬の
切断でも「接続失敗」に見えていました。今回、現在のプロジェクト・セッション・履歴を
保持したまま、2〜15秒のバックオフで再接続し、同じセッションを再購読します。

- 切断中は入力欄だけ無効化し、履歴は読める
- 4G/別Wi-Fiから使うにはTailscaleなど**到達可能なURL**が必要
  （`192.168.x.x` のLAN URLはセルラーからは届きません）
- v1.0.1のCodex/Claude/DSH履歴自動取り込みも含む
- iOS **0.4.1** / Android **0.5.1** / agentd **0.6.1** / Desktop **1.0.1**
