# Agent Remote v1.0.0 — desktop host app

The PC side is now a downloadable app. **No Node.js, npm, or terminal setup is required**
on the target Windows/macOS machine.

## What's new

- **Agent Remote Desktop 1.0.0** for Windows and macOS.
  - Electron bundles its own Node runtime, agentd 0.6.0 and all agentd production
    dependencies.
  - Detects **DeepSeek Harness, Codex and Claude Code**, starts the host, and shows the
    pairing QR automatically.
  - Also detects Cursor, VS Code, Windsurf, Aider, Gemini CLI and OpenCode for inventory;
    only DSH/Codex/Claude are driven by the current adapters.
  - Choose network interface, port, allowed folders, and optional encrypted relay sync.
  - The phone apps are unchanged and protocol-compatible (iOS 0.4.0 / Android 0.5.0).
- Windows installers: x64 NSIS installer + portable x64 exe. macOS: Apple Silicon dmg and
  zip. Builds are unsigned; first launch needs the OS warning confirmation.
- Coding CLIs themselves are not silently installed or authenticated. Install and sign in
  once per tool; the desktop app detects them.

## Downloads

- `AgentRemote-Setup-1.0.0.exe` — Windows x64 installer
- `AgentRemote-1.0.0-x64.exe` — Windows x64 portable
- `Agent.Remote-1.0.0-arm64.dmg` — macOS Apple Silicon
- Existing APK/IPA remain attached for the phone clients.

## 日本語

PC側をダウンロードするだけのアプリにしました。**Windows/macOSにNode.js・npm・ターミナル
設定は不要**です。

- **Agent Remote Desktop 1.0.0**（Windows / macOS）
  - ElectronにNodeランタイム、agentd 0.6.0、依存関係を同梱
  - DSH / Codex / Claude Codeを自動検出し、ホスト起動とペアリングQR表示まで自動
  - Cursor、VS Code、Windsurf、Aider、Gemini CLI、OpenCodeも検出（操作は未対応）
  - ネットワーク、ポート、許可フォルダ、暗号化リレー同期を設定可能
  - スマホアプリは変更なし・互換（iOS 0.4.0 / Android 0.5.0）
- Windowsはx64インストーラーとportable exe、macOSはApple Silicon dmg/zip
- 署名なしのため初回起動時にOSの警告確認が必要
- コーディングCLI自体の自動インストール・認証は行いません。各ツールを通常どおり
  インストールし、一度ログインしてください
